# Java Calculator

## About the Project
This is my first Java project: a simple console-based calculator developed using Core Java.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Division-by-zero handling
- User input using Scanner

## Technologies Used
- Java
- Scanner
- Switch Statement

## Concepts Practiced
- Variables and data types
- User input
- Conditional statements
- Switch case
- Arithmetic operators

## How to Run
1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Compile the program:

   `javac Calculator.java`

4. Run the program:

   `java Calculator`

## Learning Outcome
Through this project, I practised Java fundamentals and learned how to develop a simple interactive console application.
